# AP12 — Recursos Recomendados para Data Science y ML en Ventas

## 1. Libros — Nivel Básico

### Python y Herramientas
- **"Python for Data Analysis"** — Wes McKinney (O'Reilly).
  Guía oficial de pandas. Esencial para manipulación de datos de ventas.
- **"Python Data Science Handbook"** — Jake VanderPlas.
  Cobertura completa: NumPy, Pandas, Matplotlib, Scikit-learn.
- **"Automate the Boring Stuff with Python"** — Al Sweigart.
  Automatización de tareas repetitivas con Python. Gratuito online.

### Machine Learning General
- **"Introduction to Statistical Learning" (ISLR)** — James, Witten, Hastie, Tibshirani.
  El mejor libro introductorio. Gratis PDF. Aplicaciones en R y Python.
- **"Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow"** — Géron.
  Práctico, con ejemplos de código. Cubre todo el pipeline ML.
- **"Data Science from Scratch"** — Joel Grus.
  Implementa algoritmos desde cero para entender fundamentos.

### Matemáticas
- **"Statistical Thinking for Data Science"** — Brian D. Zaharatos.
  Enfoque práctico, no demasiada teoría.
- **"Naked Statistics"** — Charles Wheelan.
  Estadística explicada sin matemáticas complejas. Ideal para conceptos.

## 2. Libros — Nivel Intermedio

### Machine Learning
- **"The Elements of Statistical Learning" (ESL)** — Hastie, Tibshirani, Friedman.
  El clásico teórico. Profundo y riguroso. Gratis PDF.
- **"Feature Engineering for Machine Learning"** — Alice Zheng, Amanda Casari.
  Técnicas de feature engineering con ejemplos prácticos.
- **"Applied Predictive Modeling"** — Kuhn, Johnson.
  Enfoque aplicado con estudios de caso.

### Deep Learning
- **"Deep Learning with Python"** — François Chollet.
  Escrito por el creador de Keras. Claridad excepcional.
- **"Neural Networks and Deep Learning"** — Michael Nielsen.
  Gratuito online. Explica conceptos de manera intuitiva.
- **"Deep Learning" (Goodfellow, Bengio, Courville)** — El "libro de texto" del DL.

### NLP
- **"Natural Language Processing with Python"** — Bird, Klein, Loper.
  Libro oficial de NLTK. Gratuito online.
- **"Speech and Language Processing"** — Jurafsky, Martin.
  El libro de referencia en NLP. Gratuito online (borrador).

### Series Temporales
- **"Forecasting: Principles and Practice"** — Hyndman, Athanasopoulos.
  El mejor libro de forecasting. Gratis online. Usa R pero conceptos aplican a Python.

## 3. Libros — Nivel Avanzado

### Machine Learning Avanzado
- **"Machine Learning: A Probabilistic Perspective"** — Kevin Murphy.
  Cobertura exhaustiva con perspectiva bayesiana.
- **"Pattern Recognition and Machine Learning"** — Christopher Bishop.
  El clásico. Matemáticamente riguroso.
- **"Probabilistic Machine Learning: An Introduction"** — Kevin Murphy (2022).
  Versión actualizada con Python.

### MLOps y Despliegue
- **"Building Machine Learning Pipelines"** — Hapke, Nelson.
  De TFX a Kubeflow. Pipelines de producción.
- **"Machine Learning Engineering"** — Andriy Burkov.
  Ciclo de vida completo de proyectos ML.
- **"Designing Machine Learning Systems"** — Chip Huyen.
  Producción, monitoreo, mantenimiento de sistemas ML.

### Áreas Específicas
- **"Recommender Systems: The Textbook"** — Charu Aggarwal.
  Referencia completa en sistemas de recomendación.
- **"Causal Inference: The Mixtape"** — Scott Cunningham.
  Inferencia causal aplicada. Negocios y ventas.

## 14. Roadmaps de Aprendizaje

### Básico (0-6 meses)
1. Python: tipos, listas, dicts, control de flujo, funciones
2. pandas: DataFrames, filtros, groupby, merge
3. matplotlib / seaborn: visualización básica
4. scikit-learn: regresión, clasificación, train/test
5. Proyecto simple: predicción de ventas con regresión lineal

### Intermedio (6-12 meses)
1. Feature engineering: codificación, escalado, lags
2. Ensemble models: Random Forest, Gradient Boosting
3. Cross-validation y hyperparameter tuning
4. NLP básico: TF-IDF, NER, sentimiento
5. Clustering: K-Means, segmentación de clientes
6. Series temporales: ARIMA, Prophet
7. Recomendación: collaborative filtering, content-based
8. Proyecto: sistema de recomendación de productos

### Avanzado (12-24 meses)
1. Deep Learning: TensorFlow/PyTorch, MLP, CNNs, RNNs
2. NLP avanzado: Transformers, BERT, fine-tuning
3. Sistemas híbridos de recomendación
4. MLOps: MLflow, Docker, FastAPI, CI/CD
5. A/B testing y evaluación online
6. Fairness y debiasing en modelos
7. Arquitecura de datos y feature stores
8. Proyecto completo: end-to-end ML system en producción
